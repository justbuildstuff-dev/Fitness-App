## Running Tests

Tests are run via the CI pipeline which handles mock generation automatically.

To run locally:
```bash
cd fittrack
dart run build_runner build
flutter test test/widgets/templates/
```

## Dependencies

Tests with mocking require mocks to be generated by build_runner:
- `my_templates_screen_test.mocks.dart` - Generated from `@GenerateMocks([TemplateProvider])`

Run `dart run build_runner build` to generate mocks before running tests locally.
